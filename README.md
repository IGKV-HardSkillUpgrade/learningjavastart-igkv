# StartJava

Тут сборник задач, которые были выполнены в ходе изучения основного синтаксиса языка Java. В данных проектах не преследовалось цели применять ООП. Основная задача была изучить:
  - Структуру и жизненный цикл программы: Настройка точки входа (main), процессы компиляции и интерпретации байт-кода JVM.
  - Управляющие конструкции: Реализация сложной логики с использованием ветвлений (if-else, switch) и циклов (for, while, do-while).
  - Работа с памятью: Анализ выделения статической и динамической памяти, принципы работы сборщика мусора (Garbage Collection) и управление ссылочными типами.
  - Типизация данных:
    - Примитивы: Изучение размера, диапазона и побитовых операций над простыми типами (byte, int, double и др.).
    - Ссылочные типы: Устройство массивов и строк в памяти, работа с изменяемостью (StringBuilder vs String).
  - Ввод-вывод: Организация взаимодействия с пользователем через стандартные потоки (System.in, System.out).
  - Структуры данных: Реализация алгоритмов с использованием базовых коллекций и освоение механизма дженериков (Generics) для обеспечения типобезопасности.
